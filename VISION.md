# GOSPEL AI — Voice Studio Roadmap

## The ingenious part: Voice DNA + Message DNA

GOSPEL AI should not merely turn text into speech. It should preserve a reusable **Voice DNA profile** and a separate **Message DNA profile**.

### Voice DNA

Built only from the owner's authorized recordings:

- English reference
- French reference
- speaking-rate calibration
- silence/pausing characteristics
- loudness normalization
- reference quality checks

The raw recordings remain private and are mounted into the inference runtime.

### Message DNA

Before synthesis, the application can optionally structure a message into:

1. Opening
2. Scripture
3. Teaching
4. Illustration
5. Prayer
6. Call to action
7. Closing

The user remains in control of the final wording.

### Three production modes

**VOICE** — text → personal voice audio

**SERMON** — message → structured narration → personal voice audio

**GOSPEL VIDEO** — narration → scripture/background visuals → subtitles → MP4

### Quality gate

Every generated file should pass:

- duration check
- silence check
- clipping check
- sample-rate check
- language check
- output-file integrity check

Only then should it appear as a downloadable production.

This architecture keeps the voice engine replaceable while allowing GOSPEL AI to grow into a complete personal gospel-media studio.
